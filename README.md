These are several projects I've developed throghout the years during my PhD and as side projects. Here is a detailed list of what they do:
1) TicTacToe is a TicTacToe game in C++;
2) RockPaperScissors is a rock, paper, scissors game in C++;
3) Expansiononlyh.nb is a Mathematica file that computes the J-height invariant and J-Taylor series invariant of a hyperbolic-regular line in the Hirzebruch surface containing curled tori;
4) expansionmovertheline.nb is a Mathematica file that computes the J-height invariant and J-Taylor series invariant of the hyperbolic-regular line of the modified Jaynes-Cummings model;
5) iftheyannoyme.nb is a Mathematica file that computes the affine invariant of a hypersemitoric system with a pleat containing an elliptic-elliptic values in its boundary;
6) polytope for more general hypersemitoric systems.nb is a Mathematica file that computes the affine invariant of 3 simple hypersemitoric systems;
7) sqldatacleaning.sql and exploratorydata.sql are two side projects I did on a data set when I was begginng to learn SQL on my own to try and put my knowledge to the test.
8) collatz.ipynb is a simple python code, where given a natural integer n it gives the number (or numbers) between 0 and n where the number of steps for the collatz algorithm is the highest, and it gives the number of steps.
